# Идеи к реализации

Реестр идей для будущих вариантов. Сейчас **пуст — чистый лист**.

Сюда попадают только те идеи, которые ты обговариваешь с планирующим агентом: он предлагает гипотезы, ты отбираешь, и отобранное просто записывается сюда для реализации. Никаких заранее заготовленных предположений здесь нет.

## Как добавить идею

1. Обсуди идею с планирующим агентом.
2. Запиши её строкой в таблицу ниже.
3. Реализация берёт **одну** идею — это один вариант по [instructions.md](instructions.md).

Правило записи: одна идея — одна строка; формулировка должна быть проверяемой (что меняем и как поймём, что стало лучше). Гипотезы, которые ещё не отобраны, в таблицу не попадают.
