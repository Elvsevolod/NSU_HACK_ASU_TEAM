# Решение № 1 — baseline-nlp

## Фича

Исходный NLP baseline организаторов: сопоставление шагов с обработчиками через код фронтенда и BM25, затем обход возможных вызовов без анализа условий. Родительского решения нет. Сохранён самостоятельный снимок двух необходимых скриптов.

## Повторный запуск

Из папки этого решения:

```bash
python3 -B code/baseline_nlp.py ../../tt-challenge/skeleton/trainticket.json.gz ../../tt-challenge/targets/trainticket ../../tt-challenge/scenarios/*.json -o submission.json --explain
python3 -B ../../tt-challenge/platform/evaluate_golden.py ../../tt-challenge/gold/S0.json submission.json
```

Зависимости — стандартная библиотека Python 3.11. Исследуемое приложение не запускается.

## Ограничения

Baseline может выбрать несколько обработчиков для одного шага, включает лишние ветки и не переносит состояние между шагами. Разница с S0 сохранена в `benchmark/s0_diff.json`. Ответ совпадает с примером организаторов, но на сайт нами не отправлялся.
