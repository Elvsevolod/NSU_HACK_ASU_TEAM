## Проблема и исправление

Исходный объект содержит `active=false`. Первый путь устанавливает `active=true`, второй ничего не меняет. Прежний `run_paths` копировал состояние сценария, но передавал обоим путям один объект параметра: получались результаты `True/True`, исходный вход тоже менялся. Теперь состояние и параметры копируются **совместно для каждого выполнения**, включая консервативный перезапуск. Получаются `True/False`, исходный объект сохраняется.

Совместное копирование сохраняет ссылки между двумя параметрами и между параметром и состоянием. Раздельная копия каждого значения нарушила бы эту семантику. Переиспользован существующий `clone_environment`, который сохраняет неизменяемые AST-узлы. Обычный вызов `Engine.run` продолжает моделировать Java-передачу ссылок; владение изолируется на границе replay. Runtime-правка ограничена `analyzer/paths.py`.

## Проверки

Добавлены 11 тестов: **7 падают, 4 проходят на неизменённом № 20**. Проверены DTO, List, Map, исключение, повторное выполнение записи до ветвления, две ссылки на объект, совместный граф параметров и состояния, HTTP-копирование тела и неизменяемый AST callback. Проверка циклического снимка является положительным контролем существующего helper, а не заявлением о новой поддержке циклических входов Java. Унаследованные 1120 тестов не менялись. [Сводка](benchmark/tests.json), [ревью и ограничения](benchmark/development-review.json).

[Три новых графа](benchmark/input-replay-graphs.json) из двух сервисов и двух таблиц улучшились с **0/3 до 3/3**. В каждом непустые executes, calls, remote и data. Один случай проверяет пропущенную ветвь, два — лишнюю ветвь из-за повторной записи; эталоны сохранены до построения прогноза. [Результат № 20](benchmark/input-replay-parent20.json). Это синтетическая проверка replay, а не полный тест понимания естественного сценария.

Сохранены прежние **51/53** точных графа общей панели, **4/4** складских HTTP-цепочек, 12 проб Petclinic/PiggyMetrics и ограниченная цепочка состояния Petclinic GET → PUT → GET. Полного независимого HTTP/security-эталона другого приложения нет. [Пробы](benchmark/public-projects.json), [граф Petclinic](benchmark/petclinic-body-graph.json).

При проверке фикстур найдены прежние границы: field `++` не эквивалентен поддержанной явной записи поля, а циклические entry-аргументы ломают JSON-сигнатуру контекста вызова. Они не исправлены и не выданы за результаты этой версии. Проверка записи до ветвления использует явное присваивание. [Полные границы](DIAGNOSTICS.md).

Проверены 4592 защищённых файла: 4591 сохранён по SHA-256; общий каталог дополнен № 22. Предыдущие варианты, исходный пакет, образец и параллельный № 13 сохранены. [Проверка](benchmark/protected-files.json).

Польза нового делегирования оценена: для небольшой доказанной правки дополнительный запуск не нужен; предыдущая read-only консультация закреплённого бесплатного DeepSeek не вернула ответа. После упаковки в отдельном журнале OpenCode обнаружен **Rate limit exceeded** на обоих запросах; JSONL ошибку не показывал. Процесс и его собственная группа остановлены; повтор без новых данных о доступности запрещён. [Диагноз и завершение](benchmark/deepseek-followup.json). Код № 22 написан и проверен Codex; принятых новых идей/правок DeepSeek нет, платная или другая модель не использовалась. [Запись](benchmark/deepseek-development.json).

## Воспроизведение

Из каталога варианта, Python 3.11:

~~~sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONHASHSEED=0 .venv/bin/python -B code/offline_run.py --source /path/to/project --skeleton /path/to/skeleton.json.gz --context /path/to/context --scenarios /path/to/scenarios --output /tmp/submission.json --report /tmp/analysis-report.json
.venv/bin/python -B code/verify_run.py --submission /tmp/submission.json --report /tmp/analysis-report.json --output /tmp/verification.json
PYTHONPATH=code .venv/bin/python -B -m pytest code/tests -q -p no:cacheprovider
PYTHONPATH=code .venv/bin/python -B checks/check_input_replay_graphs.py --code code --work /tmp/new-replay-graph-work --output /tmp/replay-graphs.json
~~~

Контрольные входы: `--source ../../tt-challenge/targets/trainticket`, `--skeleton ../../tt-challenge/skeleton/trainticket.json.gz`, `--context ../../tt-challenge/context`, `--scenarios ../../tt-challenge/scenarios`. Path-limit=4; constraints включены. Эталон читается отдельной проверкой после построения. Сервисы и JVM не запускаются. ZIP самостоятельный, с корневым ответом; полные диагностические отчёты и временные фикстуры исключены.
