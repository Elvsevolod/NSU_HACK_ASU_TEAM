## Воспроизведение

Из каталога этого варианта, с входным пакетом организаторов в `<challenge-root>`:

```sh
cargo build --release --locked --manifest-path code/Cargo.toml -p semarch-cli
./code/target/release/semarch tt-export <challenge-root> --out reproduced-submission.json
cmp submission.json reproduced-submission.json
```

Первой сборке может потребоваться сеть для зависимостей Cargo. Входной пакет и сервисы Train Ticket не запускаются. Сам анализ и построение ответа реализованы на Rust; Python используется только внешним валидатором организаторов.
