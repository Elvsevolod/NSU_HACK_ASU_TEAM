## Реализованная граница

При финальном неподдержанном вызове или отсутствии тела метода поля достижимых объектов и состояние Map ослабляются. Идентичность объектов сохраняется. Неизвестная форма списка не заменяется фиктивным пустым списком: ссылки на него становятся неизвестными в живых окружениях. Учитываются вложенные объекты, циклы, ссылки вызывающего метода, копии при объединении ветвей и уже вычисленные аргументы вложенного вызова.

Сохраняются варианты нормального завершения и исключения неизвестного типа. При исчерпанном бюджете непроверенное исключительное продолжение отражается диагностикой. Само возможное исключение не добавляет весь скелет метода и не выполняет заведомо ложную ветвь. Новый отчёт `opaque_call_effects` содержит место, тип приёмника, изменённые абстрактные объекты и статус продолжения. Новые значения и идентификаторы отсутствующих методов не создаются.

Слишком широкая часть модели — ослабление всех известных таблиц, когда внешний write footprint отсутствует. В частности, имя `info` не доказывает чистоту; фасад SLF4J допускает разные providers и отложенный `toString()`. Слепое объявление логирования чистым ради метрики отклонено. Следующему варианту нужны проверяемые модели эффектов, а также разделение неизвестного значения и неизвестной операции. [Границы](DIAGNOSTICS.md), [ревью](benchmark/development-review.json).

## Независимая проверка

23 новых теста: 19 поведенческих проверок дают 16 отказов и 3 положительных контроля на неизменённом № 20; ещё четыре проверяют новые внутренние инварианты и не засчитаны как улучшения над родителем. В 16 унаследованных проверках явно учтён новый протокол альтернатив нормального/исключительного завершения; прежние результаты нормальных путей сохранены. Исправлена сама новая фикстура: ненулевая реализация интерфейса подаётся параметром, вместо неинициализированного поля. Изменение затронуло только тест, полный набор повторён; runtime измерения остался прежним. [Тесты](benchmark/tests.json), [переход фикстуры](benchmark/test-fixture-transition.json).

[Три графа видимых продолжений](benchmark/opaque-graphs.json) улучшились с **1/3 до 3/3**; во всех непустые executes/calls/remote/data. Эталон задаёт продолжения за непрозрачным вызовом, а не его неизвестные внутренние вызовы. Сохранились **51/53** на прежней панели, **4/4** складских HTTP-цепочек, 12 проб Petclinic/PiggyMetrics и ограниченная цепочка Petclinic GET → PUT → GET. Это не полный эталон HTTP/security другого реального приложения.

Поиск заменяемых ссылок пропускается, когда изменять ссылки не требуется. На одном парном локальном прогоне ответ всех восьми сценариев совпал байт в байт, время изменилось со 105,472 до 86,643 с. RSS выросла; общий выигрыш на других проектах не заявляется. [Проверка оптимизации](benchmark/optimization-check.json).

Проверены 4354 файла: 4353 сохранены по хешам; в общем каталоге добавлена только запись № 21 и событие возврата лучшей посылки. Прежние варианты и исходные входы сохранены. Код № 13 не исследовался и не изменялся. [Хеши](benchmark/protected-files.json). Для разработки запущен закреплённый бесплатный DeepSeek с read-only разрешениями. После первого ожидания без ответа/ошибки та же сессия продолжена с ожиданием до часа; при упаковке ответа ещё нет, принятых идей и делегированных правок в № 21 нет. Результат проверит часовое продолжение этого чата; другая модель не использовалась.

## Запуск

Из каталога варианта, Python 3.11:

~~~sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONHASHSEED=0 .venv/bin/python -B code/offline_run.py --source /path/to/project --skeleton /path/to/skeleton.json.gz --context /path/to/context --scenarios /path/to/scenarios --output /tmp/submission.json --report /tmp/analysis-report.json
.venv/bin/python -B code/verify_run.py --submission /tmp/submission.json --report /tmp/analysis-report.json --output /tmp/verification.json
PYTHONPATH=code .venv/bin/python -B -m pytest code/tests -q -p no:cacheprovider
PYTHONPATH=code .venv/bin/python -B checks/check_opaque_graphs.py --code code --work /tmp/new-opaque-work --output /tmp/opaque-graphs.json
~~~

Контрольные входы: `--source ../../tt-challenge/targets/trainticket`, `--skeleton ../../tt-challenge/skeleton/trainticket.json.gz`, `--context ../../tt-challenge/context`, `--scenarios ../../tt-challenge/scenarios`. Path-limit=4, constraints включены. Эталон читает отдельная проверка после построения. Приложения и JVM не запускаются. ZIP содержит корневой ответ и самостоятельный код; большие диагностические отчёты исключены.
