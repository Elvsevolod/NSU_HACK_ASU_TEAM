# Проверенный браузерный срез

UI-факты извлекаются Tree-sitter JavaScript и html5lib; backend по-прежнему выполняет одно общее Python-ядро. Для конкретных примитивных операций используется QuickJS-NG. Приложение, JavaScript-функции, сервисы и импорты исследуемого проекта не запускаются.

`Grounder` строит UI-индекс один раз на проект. Кнопочное действие остаётся лексической гипотезой. URL, тело и заголовки затем вычисляются из исходного выражения запроса. Заявленное значение проверяется против вычисленного payload; оно не подменяет результат умножения, преобразования или сериализации. При конфликте запрос не подтверждается.

## Значения и состояние

- Символический UUID из ядра представлен отдельным типом, обычный объект с ключом `__symbol__` не может его подделать. JSON.stringify/parse и Storage сохраняют идентичность без выдумывания конкретных байтов UUID.
- Конкретные JS Number, -0, NaN, Infinity, coercion/equality, UTF-16, parseInt/parseFloat и JSON обрабатывает закреплённый движок. Символьная JS-арифметика остаётся неизвестной.
- Каждый путь и сценарий получает собственное состояние браузера. sessionStorage и localStorage разделены. Запись происходит после успешного ответа и поддержанного callback. Известное исключение останавливает дальнейший сценарий, ранний return завершает callback.
- Неизвестный статус или эффект обесценивает соответствующие записи. Это ограниченная модель эффектов, не полная семантика произвольных callback и свойств JavaScript.
- Известное исключение в префиксе, включая неиспользуемый результат JSON.parse и присваивание поля null, не позволяет объявить выполнение серверного метода.

## HTTP

jQuery: GET по умолчанию; плоский object data становится URL-encoded параметрами, независимо от contentType. JSON.stringify меняет байты данных, Content-Type задаётся отдельно. Header overrides учитывают регистр. Вычисляется полное выражение `data`, включая поддержанные снимки объекта после присваиваний полей.

Ограниченный AngularJS `$http` отличается: object data преобразуется в JSON, POST/PUT/PATCH имеют JSON Content-Type по умолчанию; `$scope` связывается с формой. Произвольный AngularJS lifecycle и `.success/.then`-цепочки пока не понижены. После известного HTTP-префикса такая цепочка останавливает модель с диагностикой. Наличие `withCredentials` отражается как неизвестное предусловие cookie/security; его истинность не доказывает аутентификацию.

FastAPI scalar `Form()` поддержан в default и `Annotated`, включая alias; Spring MVC RequestParam читает form/query. Form model, multipart/file upload, полная Pydantic/Bean Validation и все converters не реализованы. Повторяющиеся/вложенные поля UI и неподдержанный processData диагностируются. Явный JSON Content-Type без сериализации object data не превращает URL-encoded тело в JSON.

Политики `beforeSend`, AJAX setup/prefilter/transport, custom codecs и составное действие с несколькими запросами не моделируются как точное одиночное выполнение. Сведения видны в `frontend` и диагностике отчёта. Модерные fetch/axios, TS/TSX/JSX, Vue SFC, inline scripts, полный DOM, загрузка страницы, select defaults, cookies и CORS требуют следующих адаптеров/контрактов.

## Дополнительный входной контракт

Начальное хранилище можно задать JSON-контекстом:

```json
{"tables":{},"browser":{"storage":{"sessionStorage":{},"localStorage":{"layout":"compact"}}}}
```

Ключи и значения Storage здесь — строки. Явно предоставленная карта считается полной: отсутствующий ключ даёт null. Неуказанное хранилище неизвестно. Этот контракт не означает, что браузер стартует с пустым состоянием по умолчанию.

Известный пользовательский ввод в конкретный шаг задаётся отдельно:

```json
{"action":"Create card with quantity=4","ui_inputs":{"dom":{"#quantity":"2"}}}
```

Если исходник умножает контрол на два, конечный payload должен оказаться 4. Допустимые пространства — `form`, `dom`, `dom_text`, `storage`, `url`; Storage вложен по имени хранилища. Значения могут ссылаться на историю через существующий `$ref`. Это проверяемое дополнение к естественному языку, не требование переписать сценарии организаторов вручную.

## Проверки и границы доказательств

`code/tests/test_native_js.py` проверяет операции upstream и границу запуска. `test_ui_integration.py` содержит новые ручные сценарии, независимые от предметной области Train Ticket. Ещё 60 чистых тестов перенесены из № 14 с заменой импортов.

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B development/benchmark_ui.py
```

Сохранённая fixture содержит Java gateway, Python каталог, SQLModel-хранилище и простой HTML/JS. По естественному тексту получены ровно 6 executes, 1 calls, 2 remote и 2 data; тело и состояние совпали с ручным ожиданием. Холодный/тёплый CLI с разными hash seed совпали. UUID проходит через JSON и Storage и используется в URL следующего запроса. Параметры, время подготовки/анализа, RSS, число и время чистых JS-операций — в [verification.json](benchmark/ui-integration/verification.json).

Это синтетический пример с эталоном автора реализации. Он подтверждает конкретную интеграцию, но не переносимость полного браузерного/HTTP/security-графа независимого публичного приложения. Семь прежних публичных проверок тел и десять проб поиска обработчика сохраняют более узкий объём. Универсальность и нужное качество пока не достигнуты.

Четвёртый этап добавляет 8 публичных HTTP/security-трасс с явным запросом и исходными dependencies: [FASTAPI.md](FASTAPI.md). Он не доказывает полный браузерный lifecycle этого публичного приложения.
