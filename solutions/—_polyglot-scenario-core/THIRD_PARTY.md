Tree-sitter, его Java-грамматика, SQLGlot, Z3 и PyYAML используют MIT. У LibCST есть также части под PSF и Apache 2.0: полное уведомление сохранено. Лицензии находятся в [third_party/](third_party/); [provenance.json](third_party/provenance.json) содержит версии, адреса проектов и SHA-256 файлов лицензий. Для первых пяти пакетов, кроме Z3, уведомления скопированы из установленных дистрибутивов. Уведомление Z3 получено из официального репозитория; его источник: [LICENSE.txt](https://github.com/Z3Prover/z3/blob/master/LICENSE.txt).

Прямые зависимости закреплены в [requirements.txt](requirements.txt), всё проверенное окружение — в [requirements.lock.txt](requirements.lock.txt). Изученные upstream-файлы и журналы загрузки сохранены вне runtime, в `experiments/20261017-polyglot-scenario-core/oss-sources/`. Подключённые пакеты не изменяются. Наш код связывает их с входным скелетом, источниками значений, состоянием сценария и схемой результата.

Rank-BM25 — Apache 2.0, NumPy — BSD с уведомлениями зависимостей бинарной сборки; все четыре файла лицензий установленного NumPy объединены в сохранённое уведомление с исходными путями. В релизе Rank-BM25 0.2.2 BM25L дополнительно умножает вклад на term frequency; в проверенном GitHub master этого множителя нет. Вместо изменения upstream выбран имеющийся `BM25Plus(delta=0)`: насыщение TF, положительный IDF и нулевой вклад отсутствующего слова. На фиксированных публичных запросах top-1 изменился с 9/10 до 10/10, точный набор — с 8/10 до 9/10. Корпус небольшой и не слепой; это не калибровка достоверности. Полные лицензии — в `third_party/`, сравнение — `benchmark/retrieval-formulas.json`.

Чистое выделение контекстных span перенесено из собственного варианта № 14; исходные пути, имена функций и хеш сохранены в [reused-components.json](development/reused-components.json). Импорта его движка нет. Небольшие контракты Spring остаются нашим кодом: [model-contracts.json](development/model-contracts.json) указывает проверенные upstream-теги и git blob. Spring не подключён как исполняемая библиотека анализатора.

Польза проверяется поведением: [benchmark/oss-components.json](benchmark/oss-components.json) содержит сравнение с отключённым Z3; [code/tests/test_oss_components.py](code/tests/test_oss_components.py) проверяет SQL из JDBC/SQLAlchemy, native `@Query`, NULL, ошибки привязки Session, отложенную запись и синтаксис Python. SQLGlot читает только проверенное подмножество запросов над памятью; соединения с БД и запуск исходного приложения отсутствуют. Z3 исключает ветвь только при UNSAT. LibCST не запускает импорт исследуемого модуля, Pyre или Watchman.

Выбор этих компонентов не означает, что Tree-sitter покрывает семантику JVM, LibCST выполняет Python или Z3 понимает Spring. Семантический IR и ограниченные контракты фреймворков остаются нашим кодом. Joern, CodeQL, Semgrep, Spoon и другие системы из исследования не выдаются за подключённые компоненты.

QuickJS-NG исполняет наши фиксированные чистые операции и только подтверждённые CST примитивные литералы. Исследуемые скрипты, callback-функции, модули и приложения не запускаются. Host callbacks не зарегистрированы; контекст ограничен 8 MiB памяти, 256 KiB стека и 20 ms на операцию. Символьные значения не передаются в движок под выдуманными строками. Они сохраняются отдельными тегами; JSON-текст с таким значением остаётся абстрактным и может быть прочитан следующим шагом с тем же ID.

Установленная обёртка QuickJS-NG — небольшой отдельный проект, не сама большая кодовая база движка. Проверен её релиз `v0.17.0.1`: git submodule движка — `6d2a9bacbc9feb5c1f46f80b3cf4c25bedd2187b`. Лицензия MIT движка сохранена отдельно от MIT обёртки. JavaScript-грамматика, html5lib и six — MIT; webencodings содержит собственное BSD-уведомление. Версии транзитивных six/webencodings и все уведомления закреплены в lock/provenance.

Исходный UI-экстрактор перенесён самостоятельным снимком из собственного № 14: [ui-source-provenance.json](development/ui-source-provenance.json) хранит исходные и текущие хеши, исключённые методы и изменения. Импортов его backend-движка нет. Сохранены 60 прежних чистых тестов; они не считаются независимым авторством новых эталонов. Новые проверки границ и сквозной CLI описаны в [UI.md](UI.md). Правила сериализации jQuery, ограниченного `$http` AngularJS, scalar Form и Spring RequestParam сверены с [источниками контрактов](development/model-contracts.json). jQuery, AngularJS и Spring не запускаются; нативные Python-контракты описаны ниже.

Четвёртый этап добавляет настоящий код FastAPI/Starlette, Pydantic/pydantic-core, PyJWT и pwdlib с его Argon2/BCrypt-зависимостями. Четыре ключевых файла побайтно совпали с официальными закреплёнными GitHub-тегами: [native-contracts.json](development/native-contracts.json). Лицензии прямых и транзитивных пакетов сохранены из установленных дистрибутивов; недостающая в wheel dnspython лицензия ISC получена из официального тега v2.9.0. Исходники публичного FastAPI Template включены только как неизменённые проверочные входы с MIT-лицензией. Приложение не импортируется и не запускается. [FASTAPI.md](FASTAPI.md) различает нативную семантику библиотек, наши адаптеры и остающиеся ограничения.

Пятый этап использует парсеры javaproperties/PyYAML вместо собственного разбора строк конфигурации. Pydantic TypeAdapter проверяет численные границы ограниченных Bean Validation constraints; разрешение аннотаций, nullability и каскады остаются нашим адаптером. Java time использует стандартные `datetime` и `zoneinfo`; `ZoneInfo.from_file` читает данные из закреплённого пакета tzdata, без системного TZPATH. javaproperties — MIT, tzdata содержит Apache 2.0 и уведомление о публичных данных IANA; все файлы лицензий сохранены. CPython входит в окружение, его код в архив не копируется.

Производственные Java-исходники, выбранная конфигурация и Maven-дескрипторы PiggyMetrics включены как неизменённый проверочный вход с MIT-лицензией из закреплённого коммита. Это не исполняемая зависимость анализатора. Неуспешная основная цепочка сохранена в `benchmark/public-spring/results.json`: включение реального проекта в корпус не означает поддержку всего его стека. Java time — ограниченный мост, Spring MVC и Bean Validation не подключены как JVM-библиотеки. Прочитанные upstream-контракты и границы записаны в `development/model-contracts.json`.
