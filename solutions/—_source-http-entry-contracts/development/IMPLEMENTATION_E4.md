# Этапы E3 и E4 решения №33

Поддержка `JsonProperty` устранила первый дефект HTTP-входа Library: `BookOrderDTO` получает переданные userId/bookId, а READ_ONLY поля сохраняют исходные значения. Имена и access policy извлекаются из проверенной стандартной аннотации; специальных правил Library в коде нет. До изменения 26 из 31 новых проверок падали; после изменения весь набор E3 даёт 2096 passed. Источник правил — сохранённые Java-исходники Jackson 2.11.2, без запуска JVM. [Разбор E3](json-property-review/review.json), [patch](json-property-review/code.patch), [источники](json-property-preflight/sources.json).

Следующей потерей стал префикс `@FeignClient(path=...)`. E4 соединяет literal prefix с собственным interface/method mapping и различает native аннотацию и пользовательский namesake. Исправленные контрольные примеры дают 9 fail / 2 pass на неизменённом снимке E3. Итоговый набор Feign содержит 19 проверок, включая неразрешённую конфигурацию и пользовательские перехватчики. [Разбор E4](feign-review/review.json), [patch](feign-review/code.patch), [исходники OpenFeign 2.2.5](feign-preflight/sources.json).

Ранний вариант path repair дошёл до Inventory, пропустив source interceptor, который добавляет заголовок. Этот результат не принят как доказанное исполнение: финальный E4 останавливается до отправки запроса и называет source interceptor. Первый общий guard нарушил проверенную OAuth2-цепочку PiggyMetrics; сбой сохранён. Уточнение по единственному native factory return и предоставленному verified context восстановило все 17 интеграционных запусков. Exemption по имени проекта или текстовому совпадению отсутствует.

Финальный E4: 2115 тестов кода, 76 тестов checker, все 17 интеграций проходят. [Тесты](../benchmark/feign-boundary-full-02/run.json), [checker](../benchmark/feign-boundary-checker/run.json), [интеграции](../benchmark/feign-boundary-integration-02/results.json), [сохранённая неудачная интеграция](../benchmark/feign-boundary-integration/results.json).
