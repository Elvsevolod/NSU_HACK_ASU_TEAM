В распакованном ZIP входные пути можно заменить абсолютными. Запускается только наш Python-анализатор. Граф-скелет является входом. Исследуемые сервисы, JVM и локальные модели не запускаются. Аудит офлайн-прогона запрещает сеть, подпроцессы и чтение эталонов/прежних ответов.

Основная независимая цепочка создаёт аккаунт через AuthService, переносит имя из ответа в следующий GET, сохраняет изменение перед отклонённым StatisticsService запросом и Hystrix fallback, проверяет повторное создание и удалённый отказ, затем читает состояние. Проверяются wire, identity, фактические DTO и вложенные типы, полные поля записей и четыре отношения на каждом шаге. Она проходит при лимитах 1/4/8. Выпуск и криптографическая проверка OAuth-токенов вынесены в явно предоставленный post-auth контекст; полный OAuth этим профилем не проверен.

Отдельный Codex-читатель проверил oracle по закреплённым исходникам; runtime и результаты ему не предоставлялись. Первоначальные oracle сохранены, source-коррекции имеют новые версии и честно указанную хронологию. Это исследовательский профиль знакомого проекта, а не blind holdout или доказательство поддержки всех Java/Spring-приложений.
