SHA-256 ответа: `17c04894c76f18562e89b643579b33f0bcde4fb79b91c9e1c2d52c06e56fea70`. [Полные замеры](benchmark/summary.json), [сравнение с родителем](benchmark/comparison.json), [неопределённость](benchmark/coverage-summary.json).

План свойств учитывает public fields/getters, ANY-visibility setters с произвольным return type, приоритет методов, наследование и legacy-имена Jackson2. Поддержаны простые native `@JsonIgnore`, ограниченные стандартные Lombok getters/setters и конструкторы. Конфликты, изменённая конфигурация и неподдержанные аннотации получают диагностику. Основания: [Jackson2 visibility](https://fasterxml.github.io/jackson-databind/javadoc/2.13/com/fasterxml/jackson/databind/introspect/VisibilityChecker.Std.html), [JsonIgnore](https://fasterxml.github.io/jackson-annotations/javadoc/2.13/com/fasterxml/jackson/annotation/JsonIgnore.html), [Lombok](https://projectlombok.org/features/GetterSetter).

Известное отсутствие входного поля пропускает setter. Неизвестное значение и неизвестное наличие сохраняются отдельно. Порядок и повторные ключи исходного JSON сохранены; выбранный порядок getters связан с порядком созданного документа. Наблюдаемый LinkedHashMap сохраняет порядок. Для ненаблюдаемого порядка используются доказательство независимости простых записей, альтернативы или явное расширение неопределённости.

Канонический HTTP-ответ передаётся дальше после однократной сериализации. При различии wire-свойств и Java-полей полный поддержанный UI-запрос связывается структурированным телом. Например, `ready` попадает в Java-поле `isReady` через стандартный Lombok-контракт. Без достаточных исходных данных выбранное Java-значение по умолчанию не считается подтверждённым входом.

Отражённые getters/конструкторы и generated Lombok methods исключаются из экспортируемого графа по формату задания, при этом их семантика выполняется. Прямые исходные вызовы учитываются. SQL и вложенные исходные эффекты сохраняются; вымышленных вызывающих методов библиотеки нет.
