# Диагностика № 26

В итоговом прогоне неизвестные входы есть в 51/103 шагах и 144 парах «шаг — поле». Это объединение альтернатив, а не число независимых первопричин. Все сценарии partial; возможные рёбра нельзя представлять гарантированными.

Семейство http_json_binding раскрывает неподдержанный план свойств, неизвестную codec policy, порядок callbacks, construction и глубину. Отчёт analysis-report.json хранит выбор запроса, основания параметров, условия, альтернативы и operation_issues. RequestInputs сохраняет отдельно известное отсутствие поля и неизвестное наличие. Для изменённого JSON layout полный поддержанный UI body передаётся как структурированный запрос. При отсутствии такой опоры остаётся явное ограничение; общее NL-связывание по wire-схеме и полное разделение HTTP-каналов не реализованы.

Поддержана ограниченная стандартная Jackson2-семантика. Полные Jackson/JVM/Spring не заявлены. Custom creators/codecs, многие аннотации, mixins, глобальная Spring codec configuration, конфликтующие JsonIgnore overrides, field hiding, superclass constructor chaining и сложные initializers остаются границами. Нельзя утверждать, что каждая неподдержанная конструкция уже обнаруживается. Reflection-правила относятся к проекции графа, значения и отказы не пропускаются.

По умолчанию getters и public fields используются для сериализации, setters любой видимости — для записи, getter может раскрывать private field mutator. Простые JsonIgnore учитываются в обоих направлениях; owned ObjectMapper поддерживает наблюдённую FAIL_ON_IGNORED_PROPERTIES. Ненаблюдаемые HTTP codec defaults не заменяются доказанным пользовательским выбором.

Lombok поддержан по namespace и ограниченным стандартным аннотациям. isReady хранится в соответствующем поле, @Value учитывает final, source methods/varargs подавляют генерацию. Accessors, lombok.config, сложные annotation options и копирование Jackson-аннотаций остаются явными границами. Исходная принадлежность DTO сохраняется при чтении БД и переносе между сервисами.

Независимые простые property writes могут переставляться только при проверенном отсутствии дополнительных выражений, эффектов и возможного отказа в теле. Иначе исследуются альтернативы; при исчерпании бюджета значения расширяются, callbacks и их source closure отмечаются возможными. Условно неизвестное поле не вызывает гарантированно падающий setter на пути, где оно могло отсутствовать. Это приближённый анализ, не полный effect calculus.

Сохраняются ограничения native collections/streams, static storage, Java overloads/casts, фильтров, ORM и сторонних эффектов из родителя. Поток Map view остаётся открытой проверкой 52/53. Исходные сценарии независимы; исторические ответы и состояния путей не должны смешиваться.

Проверки Petclinic и PiggyMetrics ограничены их указанными компонентами. Рёбра remote/data в DTO-пробе PiggyMetrics пусты и не считаются измеренной точностью. Четыре новых синтетических графа отдельно содержат все четыре отношения. Полный oracle независимого приложения остаётся открытым.
