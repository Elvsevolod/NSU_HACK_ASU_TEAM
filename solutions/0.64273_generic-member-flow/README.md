SHA-256 ответа: `977e587c8848f6420179dcd36c826508dec3acd3ed6e77960159f3addcfdb285`. Метрики и окружение сохранены в `benchmark/summary.json`, `coverage-summary.json` и `comparison.json`. Замеры № 23 и № 24 независимы; ускорение не заявлено.

Подстановка различает владельца объявления, пространство имён аргумента и параметры типа класса/метода. Простое выведение типа и `var` используют типы выражений из исходников, а не Python-значения. Семантика сверена с [JLS 4.5.2](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.5.2), [4.8](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.8), [5.1.7](https://docs.oracle.com/javase/specs/jls/se21/html/jls-5.html#jls-5.1.7) и [5.5.3](https://docs.oracle.com/javase/specs/jls/se21/html/jls-5.html#jls-5.5.3).

Наблюдённый класс упакованного значения переносится через поддержанные поля, Map, JSON и возвраты. Известные несовместимые native casts прерывают выполнение; непроверенные generic-проекции получают диагностику, сохраняя содержимое объекта. Сведения о полях объединяются с состоянием. Проверка скрытых полей действует и при чтении.
