Сырой alias больше не меняет тип элементов списка задним числом: запись Integer в List<Long> сохраняет Integer. Типизированное чтение и распаковка проверяют фактический класс; расширение до Object сохраняет значение. Проверки зависят от потребителя после стирания типов и границ объявления метода. Основания: [javac TransTypes](https://raw.githubusercontent.com/openjdk/jdk/jdk-21%2B35/src/jdk.compiler/share/classes/com/sun/tools/javac/comp/TransTypes.java) и [JLS 4.12.2](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.12.2).

Поддержанные List-операции учитывают классы элементов, перегрузки remove, общие ссылки, версии структурных изменений и идентичность итераторов. For-each ограничивает число реально выполненных итераций; изменения коллекции не вызывают бесконечный обход Python. Stream учитывает начальную границу и диагностирует неподдержанное вмешательство. Контексты вызовов допускают циклические значения. Это ограниченные модели [List](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/List.html), ArrayList и LinkedList, а не полная JVM.

Независимые числовые контрпримеры исправлены: Number.intValue учитывает сужение или насыщение по типу получателя, BigDecimal.equals — scale, BigDecimal(double) — точное двоичное значение аргумента. Неподдержанная точность Float и слишком точная десятичная арифметика явно диагностируются. Контракт сверялся с [BigDecimal](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/math/BigDecimal.html).
