## Изменения и проверка механизмов

Представления keySet/values/entrySet сохраняют исходную карту, а не снимок списка. Добавлены операции представлений, записи Entry, проверенные отказы итератора, явные альтернативы неизвестного порядка и ограниченный порядок LinkedHashMap. Boxed-класс значения сохраняется отдельно от Python payload. Межветвевое объединение сохраняет доказанные aliases и согласованные записи в объектах вызывающего метода; условные aliases остаются неопределёнными.

Для большого копирования dst.put(k, source.get(k)) исходный код должен доказать независимость записей. Тогда содержимое не требует перебора перестановок. Порядок LinkedHashMap сохраняется только при наличии основания. Отдельные отрицательные проверки покрывают зависимые записи, общий ключ, ранний break, generic pollution, подделку служебных полей JSON, ошибки iterator, восстановление после неподдержанного изменения и поля, исключённые из JSON.

## Границы и воспроизводимость

[DIAGNOSTICS.md](DIAGNOSTICS.md) описывает поддержку коллекций, неявные casts, codecs и оставшиеся ограничения ядра. Stream над представлениями, произвольные equals/hashCode, полная подстановка generics, неизвестная длина списков при heap join и полный жизненный цикл Spring пока не поддержаны полностью. Неизвестные значения и основания рёбер не выдумываются. [Аудит входов](benchmark/input-coverage.json) и [сводка ограничений](benchmark/coverage-summary.json) относятся только к завершённому прогону. [Свидетель отсутствующих данных](checks/missing-input-witness.json) объясняет две неоднозначности и не объясняет остальные технические пропуски.

Из каталога варианта, с Python 3.11:

~~~sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONHASHSEED=0 .venv/bin/python -B code/offline_run.py --source /path/to/project --skeleton /path/to/skeleton.json.gz --context /path/to/context --scenarios /path/to/scenarios --output /tmp/submission.json --report /tmp/analysis-report.json
.venv/bin/python -B code/verify_run.py --submission /tmp/submission.json --report /tmp/analysis-report.json --output /tmp/verification.json
PYTHONPATH=code .venv/bin/python -B -m pytest code/tests -q -p no:cacheprovider
~~~

Для этого репозитория: --source ../../tt-challenge/targets/trainticket, --skeleton ../../tt-challenge/skeleton/trainticket.json.gz, --context ../../tt-challenge/context, --scenarios ../../tt-challenge/scenarios. Эталон читает отдельный evaluator после построения ответа. Offline-аудит запрещает сеть, дочерние процессы и чтение эталона. S0 повторён с другим ID и hash seed; извлечённый архив отдельно повторяет все восемь сценариев и тесты.
