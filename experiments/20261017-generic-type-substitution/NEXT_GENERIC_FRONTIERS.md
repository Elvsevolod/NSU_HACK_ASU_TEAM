Следующий кандидат: constructor-owned JSON codec и явно наблюдаемая конфигурация. В № 18 JSON null для примитива и неизвестные свойства требуют политики codec, а объявленный ObjectMapper/HTTP-client не доказывает неизменённые runtime defaults. Независимые задачи для проверки:

- Новый нативный com.fasterxml.jackson.databind.ObjectMapper() и его поддерживаемые default feature flags; отдельный тип-владелец, который нельзя подделать пользовательским JSON. Для com.fasterxml versus tools.jackson defaults различаются; не переносить документацию3.x на2.x без проверки.
- configure/enable/disable известных DeserializationFeature, aliases и copy; неизвестная настройка/module/factory/subclass оставляют диагностику и не сохраняют старую конфигурацию как доказанную.
- Определённая политика unknown-properties и primitive-null: правильное преобразование либо доказанное исключение с остановкой и корректным catch. Null boxed/reference остаётся null, missing property не равняется explicit null. Не выдумывать конструктор/initializer/setter: source callbacks — отдельный этап.
- HTTP codec/defaults зависят от реального клиента, конвертера и Spring-контекста. Не применять настройки одного локального ObjectMapper ко всем HTTP-запросам. Сначала доказанный adapter context, затем связывание DTO.

Этот путь выбран по независимым отрицательным примерам. По агрегатам всё ещё99шагов с http_json_binding,85unknown_receiver,64object_model,43external_type,22source_method. Это частоты распространения, не доказательство причины и не precision. Если новый механизм не уменьшает реальные ошибки или только скрывает предупреждения, его нельзя принимать ради счётчика.

Другие подтверждённые границы: generic scalar/checkcast вне JSON и stream над Map view — два неполных компонента панели; неизвестная длина plain-list heap join; полный JavaBeans/Spring lifecycle. Для stream нужны lazy terminal binding, тип каждого callback, порядок и осторожное моделирование вмешательства; не обещать универсальный ConcurrentModificationException по одному JDK iterator-примеру.
