# Следующий общий этап после замороженного № 16

Результат № 16: исправлены независимые ошибки типов и управления потоком; полный JSON и48/139 неизвестных входов неизменны. Не превращать это в победу над основным регрессом. Scope-guard generic-параметров сознательно сохраняет неизвестность при недоказанной подстановке.

Агрегированное покрытие ограничений, не ранжирование точности: unknown_map_state11->9, unsupported_map_key15->13, unsupported_map_view9->11, unresolved_external_type70->45. Одна цепочка может порождать много частот. Рост view-ограничений после исправления ключей — повод проверять следующее звено общей модели, без разбора отдельных сценариев.

Следующий кандидат — backed Map views: keySet/values/entrySet. Сначала независимые пробы size/isEmpty/clear/contains и отражения мутаций в обе стороны, затем entry getKey/getValue/setValue. На этом этапе порядок обхода HashMap не подменять Python-order. Несколько элементов требуют явных альтернатив/обоснованного порядка/доказанного независимого от порядка эффекта. Singleton/empty допускают точный обход. Iterator/remove, изменение карты во время обхода, view reference identity, JSON-граница и branch deepcopy должны проверяться отдельно. Отказ от неподдержанного порядка обязан оставлять диагностику и корректную неопределённость состояния, а не старые значения после мутации через alias.

Другие общие фронтиры: method references и исходные callback-вызовы, JSON/JavaBeans lifecycle с visibility/codec конфигурацией, перенос неизвестности между браузерными запросами. Нужен более широкий корпус реальных проектов с полным референсом при заявленных границах: bounded Petclinic и маленькие fixtures полной переносимости не доказывают. Native Collections/SDK, binding generic bounds и JVM-порядок сложных lvalue остаются неполными; не обещать устранение всех таких дефектов текущим вариантом.

DeepSeek проверяется по навыкам, но последний закреплённый запуск был nonretryable403. Не делать циклических повторов и не менять модель. Никаких изменений замороженного16/оценённых/параллельного13.
