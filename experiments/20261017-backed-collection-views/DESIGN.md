Implementation design:
- Constructor-owned JavaMapView(backing,kind), JavaMapEntry(backing,key_spec,version), JavaMapIterator(view,remaining specs,expected structural version,last). A business JSON dictionary cannot forge any wrapper. Prefer dict subclass with metadata-only report representation and backing references in attributes; wire must handle wrappers explicitly. Distinct view/entry wrappers do not prove distinct Java reference identity (cached view/node possible); alias self comparison true, otherwise uncertain.
- JavaMap currently stores strings in mapping and other key classes in typed_entries. Add value kind provenance: primitive boxed class cannot be guessed from Python int/str. Engine passes source-derived type for put value and view contains query/setValue args; copy/putAll preserve kinds; HTTP default untyped strings prove String, untyped numerics may remain unknown. Existing Map.equals incorrectly equates char and String values; fix with same provenance machinery required for values.contains. Unknown source or callback equals remains diagnosed, never structural DTO equality guessed.
- Track insertion key order for LinkedHashMap normal constructor, unknown order for HashMap and generic decoded Map. Copying an unordered map into LinkedHashMap preserves contents but leaves insertion order unknown. Clear resets known order. put replacing key does not reorder; put/remove/clear update versions. Typed/string key interleaving matters.
- Pure view methods size/isEmpty/clear, keys.contains/remove, entry getKey/getValue/setValue, simple intrinsic value equality. Unsupported mutators invalidate backing map. Value/source equals callbacks need Engine context and potentially order alternatives; no arbitrary Python order or false confirmed equality. Iterator/remove state/exception semantics separately tested. addAll(empty)/mutation fail-fast API nuances must not be guessed as guaranteed exceptions.
- Explicit unordered traversal via Engine.choose and run_paths budgets for observable order. Empty/singleton exact. At exhausted order budget, diagnose and conservatively widen affected mutable state/calls; never execute one chosen Python order as confirmed. Ordered LinkedHashMap traversal exact when proven. foreach and stream should consume same iterator semantics.
- Practical exact optimization candidate: source proof for foreach keySet loop with ONLY dst.put(loopKey, src.get(loopKey)) or constant value, stable native maps, no other effects/abrupt control, pairwise disjoint typed keys. Effects commute; all entries can be applied without enumerating permutations. Destination insertion order stays unknown if source order unknown. Generic source pattern only, no app names. Raw Object key ambiguity must not be relabeled as String.

Heap joins prerequisite:
- Current merge reconstructs aliases as distinct objects. Add shared memo for completed pairs across entire joined graph; active cycles can retain old conservative behavior initially. Lists must use joined children instead of returning original left list when equality happens, otherwise aliases are lost.
- Cross-method conservative if joins lose writes to original caller-owned maps/records. Capture deepcopy memo for left/right env branches so original object->clones remain retained even after local reassignment. Join clones of every originally reachable native map/record (including those no longer in final env) using same join memo, then canonicalize merged references back to original objects and apply in place. This preserves caller-visible writes and view backing.
- Conditional aliases need widening: if the same left/right heap object participates in multiple different merged pairs, mutations through one may affect another. Detect overlapping pair origins and widen affected maps/records (including view backing), not just keep same contents with identity=None. Otherwise clear through conditional alias leaves stale known values.
- Scope caution: plain Python lists cannot express unknown length in place; do not pretend [U] is an arbitrary list. Broader list heap semantics may require a branded list domain. This is a genuine remaining limitation, not permission to claim full JVM or all heap joins solved.
