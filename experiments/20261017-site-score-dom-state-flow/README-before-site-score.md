## Изменения

- Перед запросом учитываются литеральные записи jQuery text/val, порядок, условия и значения локальных переменных в точке записи. Неизвестная условная запись, цикл, асинхронный или неоднозначный писатель сохраняют неопределённость. text и val имеют отдельные состояния.
- Текст option и начальный textContent берутся из HTML5-дерева с сохранением пробелов и исключением комментариев. Дубликаты ID, динамические области, multiple-select и другие неподдержанные случаи ограничивают привязку.
- JavaScript-условия учитывают истинность 0/−1, примитивное равенство и UTF16-длины. Инверсия простого условия выбора Vue select допустима только для единственного исходного option; явный выбор пользователя не заменяется. Альтернативный API после ложного условия требует связи с тем же исходным действием и явно диагностируется.
- Фраза «без опции» больше не очищает скрытую сводку без основания в коде. Несколько запросов одного действия и неподтверждённое выполнение callback видны в диагностике.
- Предположения о запросах и состоянии переносятся дальше. Данные, полученные через неподтверждённую подготовку, больше не превращают рёбра следующего шага в confirmed. Объединение сохраняет предположения и предупреждения всех альтернатив.

Проверенные случаи и ограничения — в [DIAGNOSTICS.md](DIAGNOSTICS.md). Числовая семантика и браузер поддержаны частично. Зависимое от версии text(null) остаётся неизвестным, пока версия библиотеки не учтена адаптером. Механизм достоверности консервативен: одна неопределённость может снять подтверждение даже с независимых последующих рёбер.

## Воспроизведение

Из каталога варианта:

~~~sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONHASHSEED=0 .venv/bin/python -B code/offline_run.py --source ../../tt-challenge/targets/trainticket --skeleton ../../tt-challenge/skeleton/trainticket.json.gz --context ../../tt-challenge/context --scenarios ../../tt-challenge/scenarios --output /tmp/solution12-reproduced.json --report /tmp/solution12-report.json
PYTHONPATH=code .venv/bin/python -B -m pytest code/tests -q -p no:cacheprovider
~~~

Для другого проекта заменяются source, skeleton, context и scenarios. Готовый граф-скелет обязателен. JVM и сервисы не запускаются. Анализ выполняется без сетевых API и моделей; установка пакетов требует их доступности. [Offline-аудит](benchmark/analysis-report-offline-audit.json) не обнаружил сетевых, процессных или эталонных обращений. [Копия CLI вне репозитория](benchmark/standalone-sample-input.json) работает с входным каталогом sample.
